Universal AI GIS Studio

Version: 1.0.0 | QGIS: 4.x (PyQt6)

MCP-first AI-controlled QGIS automation platform that bridges natural language AI agents with professional GIS workflows.

Core Capabilities

🌉 QGIS Bridge

Local HTTP/JSON-RPC bridge with authentication. Execute any PyQGIS operation from external AI agents.

🤖 MCP Integration

Model Context Protocol server exposing 100+ GIS tools. Compatible with OpenCode, Codex, Cursor, and custom MCP clients.

👁 Visual Automation

Screen capture, WebSocket streaming, AI cursor with visual overlays, and macro recording/playback.

🗺 25 GIS Clusters

M01–M25 covering Data Acquisition, Vector/Raster Analysis, Georeferencing, 3D, LiDAR, Hydrology, and more.

🔍 Georeferencing Engine

Auto georeference scanned maps using computer vision and GCP intelligence with RMSE optimization.

🛡 Security & Approval

Permission manager, approval workflows, and audit logging for safe AI-driven automation.

Plugin Panels

  • Dashboard — System health, bridge status, quick actions
  • AI Chat — Natural language GIS command interface
  • Live Screen — Desktop capture, periodic screenshots, WebSocket streaming
  • AI Cursor — Visual overlay control with smooth movement, click ripple, trails
  • AI Connections — Connect OpenCode, Codex, MCP clients
  • API Providers — Configure OpenAI, Gemini, Anthropic, OpenRouter keys
  • MCP Manager — External MCP servers and tool trust levels
  • Agent Manager — 29 built-in specialized GIS agents
  • Skill Manager — Import and validate custom skills
  • GIS Clusters — Browse and execute M01–M25 cluster tools
  • Georeferencing — Auto georeference with CV and GCP
  • GCP Intelligence — Generate, validate, optimize Ground Control Points
  • Workflow Builder — Visual GIS workflow creation
  • Algorithm Discovery — Explore QGIS Processing algorithms
  • Data Manager — Load, inspect, manage layers
  • Quality Control — Geometry, topology, data validation
  • Task History — Job execution logs and audit trail
  • Security — Permissions, approvals, audit logs
  • Settings — Bridge, WebSocket, authentication configuration
  • Macro & Visual Verification — Record/playback macros, SSIM image comparison

Keyboard Shortcuts

  • Ctrl+Shift+X — Emergency Stop (all automation)

Configuration

The plugin stores configuration in %LOCALAPPDATA%\Universal AI GIS Studio\ including:

  • Bridge server host/port and auth token
  • WebSocket streaming URL
  • API provider keys (encrypted)
  • Database and log files

Architecture

  • Plugin (QGIS) — Dock widget, bridge server, PyQGIS executor
  • Bridge Server — HTTP/JSON-RPC + WebSocket for screen streaming
  • MCP Server — Exposes tools to AI agents via Model Context Protocol
  • Core — Config, logging, job manager, capability registry
  • Database — SQLite for jobs, settings, audit logs
  • Engines — Screen capture, visual automation, CV, georeferencing

Requirements

  • QGIS 4.x with PyQt6
  • Python 3.10+
  • Dependencies: websockets, pillow, opencv-python, numpy
